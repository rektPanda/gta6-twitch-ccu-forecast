Forecasts Grand Theft Auto VI's launch-day Twitch viewers hour by hour: given the first hour's print, it learns the launch-day shape from the case file's own comparables (past big game launches) — a log-ratio curve regressed on launch size, with honest per-hour quantile spreads — and writes five quantiles for each of hours 2 to 24.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
